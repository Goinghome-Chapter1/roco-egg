# 洛克王国异色生蛋规划器

一个纯前端的洛克王国异色精灵生蛋规划工具。用户录入自己拥有的异色精灵和性别后，页面会生成推荐生蛋批次、全部可行配对，并分析获得指定异色精灵所需的亲代搭配。

## 功能

- 根据现有异色精灵生成生蛋规划
- 推荐批次优先采用 `1 公 + 2 母`
- 列出库存中全部可行的公母组合
- 支持查询指定目标异色精灵的搭配方式
- 支持 TXT、CSV、TSV 文件导入
- 支持替换或追加库存
- 支持一个精灵属于多个蛋组
- 文件和规划计算全部在浏览器本地完成，不会上传用户名单
- 支持桌面和手机浏览器

## 文件导入格式

支持带表头的 CSV：

```csv
名称,性别,数量
小黑猫,公,1
章脑丸,母,2
```

也支持不带表头的 TXT 或 TSV，每行一只：

```text
小灵菇	公
恶魔叮	母
小独角兽	母
```

性别可以填写 `公`、`母`、`雄`或`雌`。数量省略时按 1 只处理。

## GitHub Pages 部署

1. 创建一个 GitHub 仓库。
2. 将本项目全部文件上传到仓库根目录，确保 `index.html` 位于根目录。
3. 打开仓库的 **Settings → Pages**。
4. 在发布来源中选择 **Deploy from a branch**。
5. 选择 `main` 分支和 `/ (root)` 目录，然后保存。
6. 等待 GitHub Pages 完成构建，即可通过下面的地址访问：

```text
https://你的用户名.github.io/仓库名/
```

项目使用相对资源路径，可以直接部署在 GitHub Pages 的仓库子路径下，不需要服务器或后端服务。

## 本地运行

不要直接双击 `index.html`，因为浏览器可能会阻止页面读取 `pets.csv`。建议在项目目录启动一个本地静态服务器：

```bash
python -m http.server 8000
```

然后访问：

```text
http://127.0.0.1:8000/
```

也可以使用 VS Code 的 Live Server 等静态网页预览工具。

## 更新数据

异色精灵目录保存在 `pets.csv`。更新时请保留以下列名：

```csv
图鉴编号,一阶精灵,蛋组,异色类型
```

一个精灵属于多个蛋组时，使用 `/` 分隔蛋组名称。
